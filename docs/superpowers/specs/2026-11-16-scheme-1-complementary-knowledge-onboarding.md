# 方案1：补充知识预训练与新任务选择性接入

日期：2026-11-16。

用户已将本聊天中确定的设计命名为“方案1”。当前为结构方案记录，模型代码尚未修改，实验尚未启动。

## 目标

提高新增任务的迁移效果，以原任务预测稳定和每任务适配参数受控为约束。将补充信息学习、任务适配、信息选择分别交给U预训练、私有LoRA及任务路由器。

## 一阶段

1. 按现有协议训练MPT主干B，保留G/S、GRL和环境分类器。
2. 冻结B，提取H=[G,S1,S2]。训练单层解码器D_GS，以H重建归一化后的输入x。
3. 冻结D_GS，以r=x-D_GS(H)为剩余信息目标。保持U编码器尺寸和掩码方式，通过已有U解码器学习重建r。
4. 对U与G、所有S施加弱去冗余约束，并保留防坍塌约束。两个解码器仅在预训练使用。
5. 原任务直接使用原MPT预测，不再强制增加U线性修正头。

## 二阶段

保留MPT原有的任务提示、S选择、投影和新任务预测塔。每个新增目标从同一U0初始化任务私有的rank=4 LoRA。

路由器使用[G,S_t,U_t]作为输入，采用无偏置单层三输出结构，分别计算G、S、U权重。U权重同时承担接入程度的控制，不增加第四个独立U开关；本版不增加分组门控、大型投影或额外判别器。

冻结B和U0基础权重，仅训练本任务的LoRA、路由器、提示、投影和预测塔。新任务之间的适配参数相互隔离。

## 复用关系

核验身份后复用同一数据划分、B权重、G/S缓存和匹配B的MPT对照。新的U源及依赖它的任务适配模型建立新版本。旧实验结果继续保留。

本方案处理新增任务接入造成的原任务干扰；原MPT联合训练本身的任务共享问题单独处理。
