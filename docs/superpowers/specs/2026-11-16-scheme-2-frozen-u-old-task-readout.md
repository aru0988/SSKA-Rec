# 方案2：冻结U的旧任务条件低秩交互读出

日期：2026-11-16。

用户将此做法确定为“方案2”，当前聚焦一阶段旧任务增强。已固定接入结构，模型代码尚未修改，实验尚未启动。

## 目标与范围

复用已有MPT主干B和预训练U，通过每个旧任务私有的轻量接入头，提高对固定U表示的二次提取能力。B、U、G/S、GRL相关模块及原预测塔均冻结，训练期间保持eval模式。

本方案不改变U预训练目标或源权重，不使用LoRA、SSF、全量U微调；不继承方案1的剩余信息U预训练及二阶段路由修改。方案1保持独立。

## 输入与输出

- h_t：原任务G/S门控融合后、进入原预测塔之前的r维表示。
- u：冻结U产生的r维表示。
- p_t：冻结原MPT的预测概率。
- 任务t只训练自己的接入头，其他任务不更新该头。

对h_t、u分别使用无仿射参数的LayerNorm，仅用于接入头输入。原预测路径使用原始表示。

## 选定结构

固定压缩维度k=4。

q_t = sigmoid(A_t [LN(h_t); LN(u)])

v_t = C_t LN(u)

delta_t = w_t^T (q_t * v_t) + b_t

A_t是2r→k无偏置线性层；C_t是r→k无偏置线性层；最终输出层是k→1带偏置线性层。输出层权重和偏置初始化为零。q_t为低维交互内部的样本条件选择权重，不再增加独立U开关、多专家路由或额外投影网络。

最终预测沿用当前代码的零增量数值保持写法：

z_t = logit(clamp(p_t, 1e-7, 1-1e-7))

p_new = clamp(p_t + (sigmoid(z_t + delta_t) - sigmoid(z_t)), 0, 1)

实现时先计算括号中的概率差，再与p_t相加，使delta_t=0时保留原预测。它是logit残差修正的数值稳定实现。

## 参数

每任务新增参数为3*r*k+k+1，不包括共享冻结的B和U。

| 数据集 | r | k | 每旧任务新增参数 |
|---|---:|---:|---:|
| Census | 128 | 4 | 1,541 |
| KuaiRand | 128 | 4 | 1,541 |
| Ali-CCP | 64 | 4 | 773 |

## 模型选择与隔离

以该旧任务标签监督增量预测。每个任务独立选择验证AUC最佳检查点，保留零修正原MPT作为候选；不再按两个任务验证AUC均值共同选点。所有依赖源和冻结状态需登记身份，已有dataset、划分和源产物复用。

方案2的作用位置是一阶段B/U准备完成后的旧任务接入子阶段。二阶段不属于本次修改范围，后续接入新任务仍使用未被旧任务修改的共享B/U源。

## 与现有接入的区别

原线性修正仅从固定U输出读取一个logit增量。方案2让原任务融合表示与U共同决定k维选择权重，再用这些权重筛选U的低秩投影。增强发生在接入头，不发生在U编码器内部。
