# 二阶段融合与U更新范围实验实施计划

**目标：** 复用原任务U线性接入实验的全部源产物，比较五种二阶段结构在Education、Sex上的独立接入效果，共50模型。

**结构：** 模型、复用加载、队列及统计分为独立模块。旧实验目录只读；新执行身份和依赖源身份分别记录。

**环境：** PyTorch 2.1.1、CUDA 11.8、Python 3.11，现有GPUHub实例；公共dataset复用。

- [ ] 模型与测试：MPT、历史ResidualHead、三路冻结/LoRA/full，核对训练参数、共用初始化、零LoRA和梯度路径。
- [ ] 复用与测试：核对固定索引、raw标签、B/U/linear哈希、旧执行身份，直接加载原feature-cache，不重新训练或复制数据。
- [ ] 队列：五配对seed、两独立新增目标、五结构，Adam .001/batch256/30轮/patience5，验证AUC最早最佳，无验证回退。
- [ ] 保存：每阶段权重、原始概率和rowid、曲线、停止原因、参数（训练/独占）、耗时、显存及UTC时间；每模型检查原任务路径逐位不变。
- [ ] 报告：AUC/Logloss全5seed均值±SD、相对MPT/残差的配对差值与95% t区间；三路三种更新方式对应比较。
- [ ] 审查：结构符合性及代码质量分别核对；本地全测试、云端烟雾测试，确认无活worker后启动唯一队列。
- [ ] 发布与监督：推送experiment/u-stage2-census-20261111；源码包不含dataset和结果；监控进程/曲线/完成阶段，不按指标修改协议。

## 固定实现决策

- 原任务线性路径使用前轮的冻结U源和线性头；新任务只使用独立复制的U，Education的结果不初始化Sex。
- 旧NewTask预测塔L2系数沿用3e-5；不对LoRA或新增融合参数额外加L2。
- LoRA rank=4，alpha=4（增量缩放alpha/r=1），两层原encoder权重及bias冻结；A随机初始化，B零初始化。
- 三路融合保留原NewTask的投影、新环境提示、specific复用和预测塔；门控改为三路。三路顺序为环境感知复用S、G、U。
- 同seed/目标的五模型从相同NewTask权重开始；三路三组从完全相同三路头权重开始。目标的训练随机种子为seed+3+目标下标。
- 资源、源码或数据故障先查明修复；已有有效阶段按身份和哈希复用，不重训已完成模型。
